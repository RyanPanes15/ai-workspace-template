AI Workspace Template

A reusable orchestration workspace for AI-assisted development across a multi-repo project. It sits above your code repos and gives any coding agent the same operating contract, workflows, verification playbooks, guardrail hooks and helper scripts.

This page is an illustrated companion to README.md. Facts are taken from AGENTS.md, workflows/*.md, docs/*.md and claude-config/; each section names its source. Diagrams are rendered with Mermaid from a CDN, so they need an internet connection.

1. What the workspace is

The workspace is a small git repo of its own. Your project's code repos are cloned (or linked) under repos/, and each is registered with a role (frontend, backend, database, reports, docs, tests, legacy/reference, infra, other) and a policy that controls what an agent may do there.

The search is keyed on the defect's shape (one sentence with zero identifiers), not on names, and the same detector is run on a known-good control to measure the noise floor. The developer decides on bundling.

17. Model routing

Tool-neutral tiers: deep for reasoning that ships or judges code, standard for interactive and verifiable work, light for formatting. Mechanical sub-stages are dispatched to cheaper subagents; the reasoning core is never downgraded. The model is chosen once per session (deep or triage shape); escalation starts a new session from the trail file, never a mid-session switch.

UnitTierEffortRationale
/analyze, /analyze-changedeephighRoot cause under uncertainty
/fix, /implement-changedeephighShips code; cross-layer rework is the costly failure
/review-prdeephighA missed blocker ships
/build, /scaffold-projectdeephighNew code and structure later work builds on
/port-featuredeephighSilent rule omission is the failure mode
/area-loopdeephighWraps analyze/fix/port

fix-verifier, completeness-verifierdeephighThe adversarial safety net
/log-triage, /db-querystandardmediumMechanical clustering / interactive SQL
/repo-overviewstandardmediumDocuments existing files; facts traced, diagrams render-checked
/stakeholder-reply, /adrstandardmediumDrafting; external text needs accuracy
Ad-hoc chatstandardmediumWorkhorse floor

Source: claude-config/model-routing.md. Audit actual-vs-intended tier and effort regularly — routing drifts silently; lower a tier or effort only after the downgrade gate (same verdicts on sample inputs, lower $/pass).
